# Hindi speech test sample

Synthetic speech generated using Gnani TTS; this is not a human recording or a claim of speaker consent.

Text: यह काल्पनिक विवरण है। राहुल चौबीस साल का है और हिंदी बोलता है।

All described details are fictional. WAV: 8 seconds, 16 kHz, mono PCM. A consenting human sample is still preferred for real STT quality evaluation.

## B1 live verification — 2 November 2026

The user selected `artifacts/b1/hindi-synthetic-8s.wav`. The smoke script called real
Gnani and Ollama APIs through the FastAPI handlers, with real Redis concurrency/usage
accounting. No microphone was opened. No transcript or extraction files were written.

A successful standalone smoke measured:

- Capability probe: **1,314 ms**, every configured model present.
- STT: **508 ms**, `prisma-v3.0`.
- Grounded turn extraction: **1,330 ms**, `gemma4:31b`, three supported fields, zero dropped,
  `degraded=false`.
- TTS: **2,251 ms**, `timbre-v3.0`, voice `Shivani`, fresh cache miss.
- Output: `out.mp3`, **74,112 bytes**, successfully decoded by FFmpeg with no errors.

These are individual measured requests, not percentile estimates. The opt-in
`@pytest.mark.live` end-to-end test also passed, including MP3 decoding. Its separately
measured latencies were probe 1,523 ms, STT 742 ms, turn 2,100 ms, and TTS 1,700 ms.

Ruff, formatting and strict mypy passed. The full non-live suite passed **95 tests**
against isolated PostgreSQL and Redis services; the opt-in live test passed separately.
Mocked tests cover
WebM conversion, 31-second/oversize rejection, Gnani retries/errors, signed local URLs,
R2 GET/PUT/signing shape, cache hits bypassing synthesis, shared leases, budget limits,
admin authorization and capability degradation/recovery. **R2 was not live-tested**;
real-provider acceptance used the documented local development cache.

From `khoj-backend`, reproduce with:

```sh
.venv/bin/python scripts/smoke_live.py --output ../artifacts/b1/out.mp3
.venv/bin/pytest -m live tests/test_live.py -s
```

Both real keys must be in the environment or backend `.env`; Redis and FFmpeg are required.
`out.mp3` is ignored by git and can be regenerated by the script.
